
MyRobocopy
===

Windowsで外部HDDにバックアップを行うバッチファイルを書いてみた。robocopyを使っているので二回目から速い。

## Description

やりたかったこと。

- Cドライブから、外付けHDDであるDドライブへコピー。
- 0時に自動で実行してほしい。
- 0時にPCがスリープ状態でも実行してほしい。
- 実行したらPCをシャットダウンしてほしい。でないと二日間放置したとき、変更がないのにバックアップしちゃってムダだから。
- PCまるごとバックアップじゃなくて、フォルダ単位で指定したい。
- せっかくなので複数世代バックアップしたい。 (既定は 14 世代)
- Dドライブはこういう構成にする。

```
Dドライブ
│
├─ ★バックアップ用のHDDです★(バックアップ用ドライブの存在フラグ)
│
├─ 01_Backup(バックアップフォルダ)
│    │
│    ├─ 2016.01.01_00.00.00
│    │    ├─ フォルダ単位のバックアップ
│    │    └─ フォルダ単位のバックアップ
│    │
│    ├─ 2016.01.02_00.00.00
│    │    ├─ フォルダ単位のバックアップ
│    │    └─ フォルダ単位のバックアップ
│    │
│    └─ 以下、GENERATION で指定した数まで続く。
│
└─ 02_BackupLogFolder(ログフォルダ)
     │
     ├─ 2016.01.01_00.00.00
     │    ├─ フォルダ単位のバックアップログ
     │    └─ フォルダ単位のバックアップログ
     │
     ├─ 2016.01.02_00.00.00
     │    ├─ フォルダ単位のバックアップログ
     │    └─ フォルダ単位のバックアップログ
     │
     └─ ログはこれまでのを全部残す。
```

## ファイル

| ファイル | 役割 |
| --- | --- |
| `robocopy_backup.bat` | タスクスケジューラから実行する入口です。ユーザ設定、スリープ抑止、シャットダウンを担当します。 |
| `backup_core.bat` | バックアップ本体です。世代フォルダの作成・再利用と robocopy を行います。電源操作やシャットダウンは行いません。 |
| `backup_sources.txt` | バックアップ対象の一覧です。 |
| `tests/run-tests.ps1` | 使い捨てのテストデータで `backup_core.bat` を検証するテストです。 |

`.bat` と `backup_sources.txt` は Shift_JIS (CP932)・CRLF で保存してください。改行コードは `.gitattributes` で CRLF に固定しています。

## 設定

`robocopy_backup.bat` の「ユーザ設定」で次の値を指定します。

| 変数 | 意味 | 既定値 |
| --- | --- | --- |
| `FLAGFILE` | バックアップ用HDDの存在フラグです。存在しないときは何もせずに終了し、シャットダウンもしません。 | `D:\★バックアップ用のHDDです★` |
| `BKFOLDER` | バックアップフォルダです。 | `D:\01_Backup` |
| `LOGFOLDER` | ログフォルダです。 | `D:\02_BackupLogFolder` |
| `GENERATION` | 保持する世代数です。 | `14` |
| `SOURCES` | バックアップ対象の一覧ファイルです。 | `backup_sources.txt` |

`backup_sources.txt` には 1 行に 1 件、`名前|コピー元パス` の形式で書きます。`#` で始まる行はコメントです。パスに `!` が含まれていてもそのまま書けます。

```
Desktop|C:\Users\username\Desktop
xampp|C:\xampp
```

## 世代管理

- 世代フォルダ名は `yyyy.MM.dd_HH.mm.ss` 形式で、OS の地域設定に依存しません。
- 世代フォルダが `GENERATION` 個未満のときは、新しい世代フォルダを作ります。
- `GENERATION` 個以上あるときは、名前がいちばん古い世代フォルダを現在時刻の名前に変えて再利用します。robocopy の `/MIR` で差分だけをコピーするため、二回目以降も速く終わります。
- `GENERATION` を減らしても、既存の世代フォルダは削除しません。不要な世代は手動で削除してください。
- ログはこれまでのものを全部残します。

## テスト

`backup_core.bat` の動作テストは Windows 専用です。`%TEMP%` 配下に使い捨てのフォルダを作り、`backup_core.bat` だけを実行します。実ドライブ、ユーザデータ、電源設定、シャットダウンには触れません。Windows 以外では改行コードと README の既定値の静的チェックだけを実行し、動作テストは `skip` と表示します。

```
powershell -NoProfile -ExecutionPolicy Bypass -File tests\run-tests.ps1
```

GitHub Actions (`.github/workflows/test.yml`) でも、push と pull request のたびに `windows-latest` 上で同じテストを実行します。

## Task scheduler

定期実行にはWindowsのタスクスケジューラを使用。

- 全般タブ
    - ユーザがログオンしているかどうかにかかわらず実行する、にチェック。
    - パスワードを保存しない、にチェック。
    - 最上位の特権で実行する、にチェック。
- トリガータブ
    - 実行間隔と時刻を記述。
    - 有効、にチェック。
- 操作タブ
    - プログラム/スクリプトにいま書いたスクリプトの場所を設定。例、"C:¥robocopy_backup.bat"
    - 開始ってところに上記スクリプトのディレクトリ名をダブルクォーテーションなしで記述。例、C:¥
    - このパスにスペースが含まれていたり、カッコが含まれているとうまくいかないっぽい。具体的には、実行はできるんだが、タスクスケジューラの実行結果が0x1になっちゃうことがあった。
- 条件タブ
    - タスクを実行するためにスリープを解除する、にチェック。
